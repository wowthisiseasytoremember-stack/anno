# Anno — Current Roadmap

**Last reconciled:** 2026-10-03

## V1 product target

Ship a useful Catholic daily devotional and pilgrimage app on iPhone with:

- Today devotional experience
- liturgical Calendar
- Map with five flagship pilgrimage routes
- Orange County / Our Lady of La Vang as the featured exemplar
- sourced content and artwork
- English-first UI/content with intentional Vietnamese support
- native Apple polish: haptics, MapKit, Spotlight, App Intents, sharing, and capability-gated system surfaces
- Free + Premium $49.99/year direction

## Apple-native expansion

Tracked in **Issue #31**.

Principle:

**ARRIVE → SEE → PRAY → REMEMBER → SHARE**

Potential features must improve one of those stages.

Keep:
- Core Haptics
- Live Activities / Dynamic Island
- Watch
- location/time/context awareness
- Vision / camera
- AR where site conditions make it reliable
- QR/NFC, optional cooperating-site beacons
- generated keepsakes via Apple system capabilities
- visionOS spatial devotional/art concepts later

Avoid:
- framework tourism
- mandatory physical verification
- continuous hidden tracking
- spiritual scoring
- floating-cartoon/loot-game sacred experiences

## Monetization

Current decision: **Free + Premium, $49.99/year direction**.

The old mixed monthly/annual paywall was excluded from the active target. If monetization ships in v1, deliberately build a small StoreKit 2 annual flow rather than restoring legacy paywall code.
